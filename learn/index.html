The Data Analyst Roadmap
1
🏁 Foundation — Spreadsheets & Data Basics
Learn Excel or Google Sheets. Understand data types, formulas, pivot tables and basic charts. This is where every analyst starts.
Excel Google Sheets Pivot Tables VLOOKUP Charts
⏱️ 4–6 weeks
2
🗄️ SQL — Query Your Data
Learn to query databases using SQL. SELECT, WHERE, JOIN, GROUP BY. SQL is the most important skill for every data analyst.
SELECT WHERE JOIN GROUP BY Subqueries CTEs
⏱️ 6–8 weeks
3
📊 Data Visualization — Tell Stories With Data
Learn Power BI or Tableau. Build dashboards that help decision makers understand data at a glance.
Power BI Tableau DAX Dashboards KPIs
⏱️ 6–8 weeks
4
🐍 Python for Data Analysis
Learn Python basics then move to pandas, numpy and matplotlib. Automate your analysis and handle large datasets.
Python Pandas NumPy Matplotlib Seaborn
⏱️ 8–12 weeks
5
🚀 Build Projects & Get Hired
Build 3–5 real projects using Nigerian or African datasets. Create a portfolio, update your CV and start applying for roles.
Portfolio GitHub CV Writing Interviews Networking
⏱️ Ongoing
